## Soluciones y proyectos

### Loma · Chatbot RAG para una ONG de ecoturismo

Asistente conversacional que atiende consultas por **WhatsApp** y desde un **widget web** embebible, respondiendo con información de los propios documentos de la organización.

- Responde preguntas a partir de documentos y contenido web de la organización.
- Deriva a una persona cuando la búsqueda no ofrece información suficiente.
- Registra contactos y los sincroniza con HubSpot para facilitar el seguimiento.

**Tecnologías:** Python · FastAPI · Gemini · Qdrant · GCP.

### Otros proyectos

- **Consulta de documentos legales:** recuperación de información documental mediante RAG. *Vertex AI · Python.*
- **AEO Tracker:** aplicación full-stack para medir y auditar la presencia de marcas en motores de IA generativa. *FastAPI · Angular · GCP.*
- **Agentes en Copilot Studio:** chatbots corporativos con herramientas personalizadas e IA generativa. *Copilot Studio · Power Platform.*
- **Procesamiento de datos:** entorno local para desarrollar procesos de extracción, transformación y carga. *AWS Glue · S3 · Docker · Terraform.*
- **Servidor MCP — práctica técnica:** integración de herramientas para consultar información meteorológica. *TypeScript · MCP SDK · Open-Meteo.*
- **Visualización de datos:** scripts para comparar indicadores entre periodos y generar gráficos para reportes. *Python · matplotlib · NumPy.*
